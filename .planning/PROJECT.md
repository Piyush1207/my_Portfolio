# Majd Portfolio Replica

## Core Value
A pixel-perfect Next.js replica of Majd's Framer portfolio, optimized for performance and featuring a custom, smooth loader animation.

## Context
Majd needs to migrate his current Framer portfolio to a custom Next.js + Tailwind CSS stack. The goal is to retain the exact visual design and animations while owning the codebase completely and implementing a unique Kael Donovan inspired page loader.

## Success Metrics (KPIs)
- Lighthouse Performance Score: 90+
- Loader engagement: 100% of users see the loader
- Visual Parity: Indistinguishable from the Framer site
- Responsiveness: Flawless across mobile, tablet, and desktop

## User Personas
- **Potential Client - Alex:** Marketing Director looking for a developer. Needs to view services and past work.
- **Framer User - Sarah:** Indie Maker interested in purchasing Framer templates.
- **Recruiter - David:** Tech Lead evaluating technical skills. Focuses on codebase quality and performance.

## Key Decisions
| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Next.js App Router | Modern React standards, great for performance | Selected |
| Tailwind CSS | Utility-first styling to closely match the visual aesthetics rapidly | Selected |
| Framer Motion | Best tool in the React ecosystem for replicating Framer's built-in animations | Selected |

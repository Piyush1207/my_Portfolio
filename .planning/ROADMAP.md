# Roadmap

**5 phases** | **14 requirements mapped**

| # | Phase | Goal | Requirements |
|---|-------|------|--------------|
| 1 | Setup | Initialize Next.js environment and global styles | SETUP-01, SETUP-02, SETUP-03 |
| 2 | Foundation | Build the layout wrapper, Header, and Footer | NAV-01, NAV-02 |
| 3 | Core Content | Build the main content sections (Hero, About, Services, etc.) | SEC-01, SEC-02, SEC-03, SEC-04, SEC-05, SEC-06, SEC-07 |
| 4 | Loader | Implement the custom full-screen loader animation | LOAD-01, LOAD-02 |
| 5 | Polish | Refine animations using Framer motion and check responsive layouts | (Cross-cutting polish) |

## Phase Details

**Phase 1: Setup**
Goal: Next.js running with Tailwind and Framer Motion ready
Success Criteria:
1. App compiles and runs via `npm run dev`
2. Tailwind classes work

**Phase 2: Foundation**
Goal: Global structure established
Success Criteria:
1. Navigation bar is present and responsive
2. Footer is present

**Phase 3: Core Content**
Goal: Replicate visual layout of the portfolio
Success Criteria:
1. Hero section matches screenshot
2. Services are presented as a grid/list
3. Contact form inputs function

**Phase 4: Loader**
Goal: Custom loader experience
Success Criteria:
1. Loader blocks view on initial load
2. Disappears smoothly after set time

**Phase 5: Polish**
Goal: Complete the replica effect
Success Criteria:
1. Scroll animations function
2. Hover animations function
